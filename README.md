# Athletex Sports Shop Platform

## Project Overview
Athletex is an online sports shop platform built with PHP. It allows users to browse, filter, and manage sports products, featuring:

- Product listings with images
- User authentication and password management
- Product management for sellers
- Responsive design using Bootstrap
- Image uploads for products

## Features
- Browse and search sports products
- Add, edit, and remove products (for sellers)
- User registration, login, and password reset
- Secure authentication and session management
- Responsive UI for desktop and mobile

## Technologies Used
- PHP
- Bootstrap (CSS/JS)
- MySQL (via `connection.php`)
- JavaScript

## Getting Started
1. Clone the repository
2. Set up a local web server (e.g., XAMPP, WAMP)
3. Import the database and configure `connection.php`
4. Access the site via your local server
